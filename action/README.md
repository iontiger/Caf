# The Secret of DentPhoto Village: 횡스크롤 액션판

마을 허브 + 액션 로그라이트(Hades, Dead Cells 계열) 방향의 1지역 프로토타입이다. 견습 해적 아울러가 부두와 동굴을 지나 깡패 선장의 배에 오른다. 칼싸움이지만 핵심은 말싸움이다. 적의 도발 대사가 끝나는 순간이 공격 타이밍이고, 그때 받아치면 적이 기절하고 아울러가 맞받아치는 대사를 던진다.

플레이: https://iontiger.github.io/Caf/ (master에 머지되면 GitHub Actions가 자동 배포). 예전 카드 데모는 https://iontiger.github.io/Caf/cards/

## 조작

| 동작 | 키보드 | 터치 |
|---|---|---|
| 이동 | ← → 또는 A D | ◀ ▶ |
| 점프 (2단) | 스페이스, ↑, W | 점프 |
| 발판 아래로 | ↓ + 점프 | ▼ + 점프 |
| 공격 (3연타) | J 또는 Z | 공격 |
| 구르기 (무적) | K, X, Shift | 구르기 |
| 받아치기 | L 또는 C | 받아치기 |
| 필살 대사 | O 또는 V | 필살 |
| 럼병 (체면 +30) | Q 또는 U | 럼 |
| 대화, 상점 | E 또는 Enter | E |
| 소리 끄기 | M | |

터치 버튼은 터치 기기에서 자동으로 나온다. 데스크톱에서 보려면 주소 뒤에 `?touch`를 붙인다.

## 들어 있는 것

- 한 판 8개 방: 일반 3, 강적(외팔이 갑판장), 일반, 떠돌이 상인, 일반, 깡패 선장. 부두 3종과 동굴 2종 지형 중에서 시드로 고른다.
- 적: 술 취한 선원(칼질), 부두 게(돌진), 병 던지는 밧줄꾼(투척, 받아치면 병이 되돌아간다), 갑판장(2연타와 돌진), 깡패 선장(3연타, 말 중간에 칼이 나오는 속임수, 돌진, 체력 절반부터 대포 사격과 게 소환).
- 받아치기: 도발이 끝나기 직전 빨간 `!`가 뜬다. 받아치면 기절, 반격 피해, 관중 웃음 +30. 연타의 중간 칼은 막기만 되고 마지막 칼을 받아쳐야 기절한다. 갑판장과 선장은 자세를 잡고 있을 때 앞에서 오는 칼을 막으므로, 받아치거나 공격 뒤 빈틈을 노려야 한다.
- 관중 웃음이 가득 차면 필살 대사: 화면 안의 적에게 큰 피해와 기절.
- 주민들의 미소 11개: 방을 깨면 문 두 개가 나오고, 문에 붙은 주민(술집 주인, 등대지기, 생선 장수)이 미소를 하나 고르게 해 준다. 두 주민의 미소를 모으면 합동 미소가 나온다.
- 술집 허브: 쓰러지면 "찰칵!" 사진에 갇히고 술집에서 깨어난다. 금니는 남고, 등대지기에게 금니를 주고 영구 강화(최대 체면, 받아치기 판정, 시작 럼병, 시작 미소)를 산다. 선장에게 한 번 지면 다음부터 속임수 공격에 노란 `!!` 예고가 보인다. 선장을 이기면 단서가 게시판에 붙는다.
- 진행 상황은 브라우저 localStorage에 저장된다.

그림은 모두 코드로 그린 임시 도형 아트이고(`src/game/textures.ts`), 효과음도 WebAudio로 합성한다. 정식 아트가 나오면 텍스처 파일만 바꾸면 된다.

## 실행

```bash
cd action
npm install
npm run dev      # 개발 서버
npm test         # 지형, 방 구성, 미소, 강화, 저장 테스트
npm run build    # dist/에 정적 파일 빌드
```

개발용 바로가기: 주소 끝에 `#boss`(선장 방), `#shop`(상점), `#room=4`, `#debug`(충돌 상자 표시)를 붙인다.

## 구조

- `src/logic/`: 화면과 무관한 규칙과 데이터 (방 구성, 미소, 적 수치, 영구 강화, 시드 난수). 테스트는 여기만 본다.
- `src/game/player.ts`, `enemy.ts`: 아울러 조작과 적 행동 패턴
- `src/game/scenes/`: 타이틀, 술집 허브, 방 진행, HUD와 터치 버튼, 카드 메뉴
- `src/game/textures.ts`, `backgrounds.ts`, `fx.ts`, `sfx.ts`: 임시 아트, 배경, 말풍선과 이펙트, 효과음
