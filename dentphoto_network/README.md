# 덴트포토 게시판 관계 분석기

덴트포토 게시판 목록을 넘기면서 글마다 **작성자**와 **댓글 단 사람**만 모은 뒤,
누가 누구의 글에 댓글을 다는지로 사람 사이의 관계를 계산합니다. 글 제목과 본문은 수집하지 않습니다.

- a의 글에 b, c, d가 댓글을 달면: b→a, c→a, d→a 연결
- b의 글에 a, e가 댓글을 달면: a→b, e→b 연결
- a와 b는 서로의 글에 댓글을 달았으므로 **끈끈한(상호) 관계**

## 준비물

Python 3.8 이상만 있으면 됩니다. 따로 설치할 라이브러리는 없습니다.

## 1. 쿠키 준비

게시판은 로그인해야 볼 수 있어서, 브라우저의 로그인 쿠키를 스크립트에 넘겨줘야 합니다.

1. 크롬에서 덴트포토에 로그인한 뒤 자유게시판(`https://forum.dentphoto.com/board/free/list.php`)을 엽니다.
2. `F12` → **Network(네트워크)** 탭 → `F5`로 새로고침 → 맨 위의 `list.php`를 누릅니다.
3. **Headers** → **Request Headers**의 `Cookie:` 줄 값을 통째로 복사합니다.
4. 이 폴더에 `cookie.txt` 파일을 만들어 붙여넣고 저장합니다.

`PHPSESSID` 값 하나만 붙여넣어도 됩니다. **Application(애플리케이션)** 탭 → Cookies에서 찾을 수 있습니다.

쿠키는 비밀번호와 같습니다. 다른 사람에게 주지 마세요. `cookie.txt`는 `.gitignore`에 들어 있어 커밋되지 않습니다.
작업이 끝나면 브라우저에서 로그아웃해 두세요.

## 2. 실행

```bash
# 최근 목록 3페이지 (약 150개 글)
python dentphoto_network.py --pages 3

# 9월 1일 이후 글 전부
python dentphoto_network.py --since 2026-09-01

# 수집 없이, 모아둔 데이터로 분석만 다시
python dentphoto_network.py --analyze-only

# 다른 게시판 (clinical, investment, politics, transfer, recruit)
python dentphoto_network.py --board politics --pages 3
```

아무 옵션 없이 실행하면 최근 5페이지를 읽습니다.
목록 한 페이지에 글이 약 50개이고, 댓글이 있는 글만 열어보므로 1초 간격 기준으로 한 페이지에 1분 정도 걸립니다.

### 이어서 수집하기

모은 글은 `output/<게시판>/posts.jsonl`에 바로바로 저장됩니다.
중간에 멈추거나(`Ctrl+C`) 로그인이 만료되어도, 같은 명령을 다시 실행하면 처음 보는 글과 댓글이 늘어난 글만 새로 읽습니다.

## 3. 결과

`output/<게시판>/` 폴더에 생깁니다. CSV는 엑셀에서 바로 열립니다.

| 파일 | 내용 |
| --- | --- |
| `pairs.csv` | 두 사람씩 짝지은 관계 순위. 서로 댓글 단 횟수와 끈끈함 점수 |
| `people.csv` | 사람별 쓴 글, 댓글 단 글, 받은 댓글, 가장 끈끈한 사람 5명 |
| `posts.csv` | 글별 작성자와 댓글 단 사람 (수집이 제대로 됐는지 확인용) |
| `network.html` | 관계도. 브라우저로 열고, 닉네임을 검색하거나 사람을 누르면 그 사람과 끈끈한 사람 목록이 나옵니다 (인터넷 연결 필요) |

## 점수 계산 방식

- **A가 B 글에 댓글**: A가 댓글을 단 B의 글 수. 한 글에 여러 번 달아도 1번으로 셉니다.
- **끈끈함 점수**: 두 방향 횟수 중 작은 쪽. 한쪽만 일방적으로 댓글을 다는 관계는 0점이 됩니다.
  예) A→B 9번, B→A 7번이면 7점 / A→B 20번, B→A 0번이면 0점(일방)
- 자기 글에 단 댓글은 세지 않습니다. 공지사항은 뺍니다.
- `--since`를 주면 분석도 그 날짜 이후 글만 대상으로 합니다.

## 주의

- 결과에는 회원 닉네임과 관계가 담겨 있습니다. 개인적으로만 보고 외부에 공유하지 마세요.
