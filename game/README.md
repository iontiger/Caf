# The Secret of DentPhoto Village

말싸움 덱빌딩 로그라이트의 1막 프로토타입이다. 견습 해적 아울러가 부두의 말싸움꾼들을 말발로 꺾고 깡패 선장에게 도전한다.

플레이: https://iontiger.github.io/Caf/cards/ (사이트 첫 화면은 횡스크롤 액션판 `action/`이다. master에 머지되면 GitHub Actions가 둘 다 배포)

## 실행

```bash
cd game
npm install
npm run dev      # 개발 서버
npm test         # 전투, 지도, 메타 진행 테스트
npm run build    # dist/에 정적 파일 빌드
```

## 들어 있는 것

- 말싸움 전투: 상대 도발의 주제(외모, 용기, 가문, 실력)에 맞는 응수 카드를 내면 받아치기(피해 2배, 도발 무효, 관중 웃음 +1). 관중 웃음 5개로 필살 대사.
- 보스는 도발 주제를 숨긴다. 대사를 듣고 짐작하거나 간파 카드를 쓴다. 보스에게 한 번 지면 다음부터 주제가 보인다.
- 1막 지도 6칸 + 보스. 칸 종류: 말싸움, 엘리트, 이벤트, 술집, 상점, 보물.
- 카드 30장, 적 6종(일반 4, 엘리트 1, 보스 1), 이벤트 5개, 단서 4개.
- 메타 진행: 판이 끝날 때마다 술집 소문 하나가 해금되어 새 카드가 보상에 나온다. 단서는 수첩에 남는다. 진행 상황은 브라우저 localStorage에 저장된다.

## 구조

- `src/game/`: 화면과 무관한 게임 규칙 (전투, 지도 생성, 런, 메타 진행, 데이터)
- `src/main.ts`: DOM 화면과 입력 처리
- `src/style.css`: 타이틀 이미지 톤을 따른 밤바다 팔레트

기획 의도와 이후 막(절벽 마을, 저택)의 계획은 프로젝트 기획서를 따른다.
